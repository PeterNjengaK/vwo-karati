# Code ownership and access

This repository is intended to remain private. Access is limited to the repository owner and explicitly invited collaborators. No open-source licence is granted by this repository. Sharing access permits recipients to copy the files; private visibility cannot prevent copying by authorised collaborators.

Never commit secrets, SSH keys, member databases, or backup files. The data directory and environment files are excluded. Production database backups are managed separately; a GitHub source copy does not replace them.
